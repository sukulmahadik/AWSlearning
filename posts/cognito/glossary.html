Term Meaning
Access token Token your API reads to decide what a request may do
App client An application's registration inside a User Pool, with its own settings
Assume a role Temporarily borrow an IAM role's permissions
Authentication Proving who you are
Authorization Deciding what you are allowed to do
Authorization code A short-lived ticket returned after login, swapped for tokens
Broker A service that trusts upstream identity providers and issues its own tokens downstream
Callback URL Where the browser is sent after login (also called redirect URI)
Claim One fact inside a token, such as an email or a group
Client credentials flow A login where an app signs in as itself, with no user
Client ID Public name tag of an application
Client secret Private password of an application; only for server-side apps
Confidential / public client An app that can keep a secret (server) / one that cannot (browser, mobile)
Federation Accepting another system's confirmation of who a user is
IAM role A named bundle of AWS permissions that can be borrowed
ID token Token telling the app who the user is
Identity Pool Cognito service that swaps a login token for temporary AWS credentials
Identity provider (IdP) A service that holds user accounts and confirms identities (Google, Okta, a User Pool)
JWT A signed, readable token format with header, payload and signature
MFA Multi-factor authentication: a second proof besides the password
OAuth 2.0 Standard rules for an app to get access on a user's behalf without their password
OIDC OpenID Connect: a layer on OAuth 2.0 that adds the ID token and login
PKCE A one-time secret that protects logins for apps that cannot hold a client secret
Refresh token Long-lived token used to get new ID and access tokens
Resource server Your API, as defined in a User Pool, with its own custom scopes
SAML An older XML-based login standard common with company identity providers
Scope A named permission carried in an access token
STS AWS Security Token Service; issues temporary credentials for a role
Trust policy The part of an IAM role that says who may assume it
User Pool Cognito's user directory and login service; issues tokens
Authorizer API Gateway's check that runs before your code, e.g. verifying a Cognito token
Backend-for-frontend (BFF) A server that holds tokens for a website so the browser never sees them
IAM Identity Center AWS's single sign-on for employees accessing AWS accounts and work apps
Lambda trigger Your own code that Cognito runs at a fixed step of sign-up or sign-in
Managed login Cognito's ready-made, brandable login pages (formerly the hosted UI)
MAU Monthly active user: a user who signs in at least once in a month; the basis of Cognito pricing
SRP Secure Remote Password: proves a password is known without sending it
Tenant One customer company in an app shared by many companies
Token vault AgentCore Identity's store of per-user tokens and API keys for outside services
Workload identity An identity given to a program or agent rather than to a person
XSS Cross-site scripting: an attacker's script running on your web page, able to read anything JavaScript can
