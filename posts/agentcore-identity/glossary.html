Term Meaning
2LO (two-legged OAuth) OAuth client credentials flow; the agent gets a token as itself, with no user (machine-to-machine)
3LO (three-legged OAuth) OAuth authorization code flow; the user approves on a consent screen and the agent acts for them
Agent A program that uses a language model to decide what to do and calls tools to act
Agent identity A workload identity with agent-specific attributes
Agent identity directory The registry of workload identities in an account and Region (default)
AgentCore Gateway Turns APIs, Lambda functions and MCP servers into tools behind one endpoint, with inbound and outbound auth
AgentCore Runtime The managed service that hosts agents and tools
API key credential provider Stores an API key for one service in the token vault
Authorization URL The consent link returned when a user must approve access
Callback URL (AgentCore's) Where the provider sends the user after consent; registered at the provider
CompleteResourceTokenAuth The call your app makes to finish session binding
Consent portal An AWS-hosted page that collects user sign-in and consent for gateway tools
Credential provider A named configuration for getting credentials from one outside service
CustomOauth2 The credential provider type for any OAuth 2.0 server not built in
Delegation The agent acts as itself on behalf of a user, with both identities visible
Impersonation The agent uses the user's credentials directly, so it looks like the user
Inbound auth Checking who may call an agent or gateway
Inbound JWT authorizer The settings that validate callers' JWTs: discovery URL, allowed clients, audiences, scopes, claims
JWT A signed, readable token format used for logins
MCP Model Context Protocol, a standard way to offer tools to agents
OAuth 2.0 credential provider Stores a client ID and secret for one OAuth service and runs its flows
Outbound auth Supplying credentials when an agent calls another service
Return URL (your app's) Where AgentCore sends the user so your app can confirm them; registered on the workload identity
Session binding Confirming that the user who approved is the user the agent works for
SigV4 AWS's request-signing method, used for IAM-authenticated calls
Token vault Encrypted storage for tokens and keys, released only to the right agent and user
Token exchange Trading one token for another that a downstream service accepts
Workload access token A short-lived token meaning "this agent, acting for this user"
Workload identity The identity of a piece of software, such as an agent or gateway
